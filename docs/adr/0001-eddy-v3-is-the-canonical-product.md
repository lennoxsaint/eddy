# Eddy-v3 is the canonical product

The lightweight skill-first Eddy-v3 repository replaces the previous compiled Eddy implementation
and takes the public `lennoxsaint/eddy` identity at v3.0.0. The previous repository is preserved as
read-only `eddy-legacy`; only proven safety and orchestration capabilities are ported because merging
both engines would recreate duplicate editorial brains and incompatible contracts.
